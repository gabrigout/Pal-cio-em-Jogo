# Pal-cio-em-Jogo
Um simulador político de navegador, satírico e sistêmico, ambientado no Brasil fictício a partir de janeiro de 2027. Você já começa como presidente e governa por turnos (4 semanas por mês), com humor ácido sobre a política brasileira. É um jogo de gestão, sem combate e sem 3D, majoritariamente textual
